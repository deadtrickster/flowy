# The harness research

Sixteen research reports and an architecture written from them, produced
2026-08-16 while working out what a custom coding-agent harness should be.

**They are not in this repository any more.** They were internal working notes -
four round-1 reports, eight round-2 reports across three lenses, a
tree-sitter-for-codegen run, a practitioner thread, and the architecture and
review that came out of them - and a public repository is the wrong shelf for a
team's thinking-in-progress.

They live in two places now:

- **In the node**, as reports, tagged `harness-research`. `/reports` in the
  console lists them and renders them; `report_search` over MCP finds them by
  content. Each one carries the filename it had here as a tag, so a citation
  like `harness-research/r2-scout-glm.md` still resolves.
- **On the operator's disk**, at `~/Projects/harness-research`, byte-identical
  to what was removed.

They were written to the node and verified byte-identical there BEFORE they were
removed here, in that order, because the repository was the only copy that
existed in more than one place at the time.

Nothing is erased: `git log --follow harness-research/` still has every version,
and a public repository cannot be un-published by deleting a file. This is about
what a reader sees on the front page, not about the history.
